# RAJA BUNDELA

Production website foundation for ANJUL RAJA BUNDELA + RAYONE.

## Run
npm install
npm run dev

## AI
Copy .env.example to .env.local and set OPENAI_API_KEY. The key is server-side only.

## RAYONE
The supplied locked rayone-core.html is kept under public/ as the source reference. Production integration must preserve its visual behavior and public API while removing demo controls.
